# 按任务召回经验

输入是当前任务及经验包的 `index.md` 路径。用正常的文件读取能力查经验，不需要专用 MCP 或查询脚本。

这些经验来自真实迁移中的失败与修复，其中一些问题在规格生成、代码实现、收敛检查或编译通过后仍然存在，直到后续运行或视觉验证才暴露。它们用于提醒容易漏掉的具体失效模式。与当前任务相关且适用条件成立时，应将对应做法落实到方案或实现中，而不只是记录“已读”；已有实现已覆盖时无需重复工作。经验补充当前源码和规格，不替代对它们的理解。召回时不要默认只进入一个子目录：先展开可能相关的同层分支，再收窄到正文。

提醒时机由 hook／宿主配置决定；本 skill 只说明被唤起后如何按需使用经验，不另行规定启动或写前提醒流程。结合当前任务和已有输入选择相关经验，复用同一版本下已读内容；没有新相关项就继续原任务。

本 skill 可单独发布；附带的旧库诊断脚本与 hook 安装脚本只依赖 Python，不需要其他 skill 或 inquiry 内核。正常召回只读指引和相关经验，不加载脚本源码或历史转录。

1. **先看当前索引并扫描同层候选。** 从一个目录查找经验时，先完整读取该目录的 `index.md`（输出截断时续读），了解覆盖范围与子分支。把所有可能相关、或暂时不能排除相关的直接子索引一起打开；不要因为第一个看起来匹配的分支就立即下钻到 lesson。若候选分支还有子主题，先比较这些子主题的索引，再选择正文。已读且任务范围未变化的索引可以复用，无需重复阅读或遍历明显无关分支。
2. **选经验。** 在同层候选比较后，按当前要作的决策和输入中的技术特征，结合预览的时机、情境和例外筛选，不按历史项目名匹配；批量打开选中的经验，跳过已能排除的条目。对相关性仍不确定的分支，保留到索引比较完成，不要提前假定经验只会出现在某一个主题下。
3. **用于当前任务。** 已有源码、规格足以判断条件时，直接采用适用做法；关键前提不明时，只补充足以确定该前提的局部材料。当前方案已符合时继续，不为体现采用而改动。“可选检查”是按需的额外验证，不因读到经验另起验证流程，项目原有必需测试照常执行；旧包标题为“检查”的条目也按此理解。不用遍历整棵树或列出无关条目的跳过理由。

看过当前索引并完成同层候选比较后，grep、搜索、脚本和直接读取可自由组合；按分支介绍的整体含义选择相关范围，留意语义相关但用词不同的经验。搜索可以补充索引导航，但不能替代先看父索引和相关兄弟索引。已知条目可直接定位；任务或输入明显变化后再补查。

经验是有条件的历史建议。当前材料与经验冲突时核实条件，再决定采用、调整或暂缓；历史样例的数值和局部修法不自动覆盖当前要求。按需读取并用于原任务即可，无需额外标记已读、列出经验 ID/版本或提交引用、采用清单。

只有需要复核才打开来源卡；核对结论时一起看其 `unknown`，区分已观察事实与新推断。来源不可访问或目录链接损坏时注明具体缺口。发布版本、来源复核及旧 store 入口见 [使用约定](references/usage.md)，遇到这些情况再读。维护者接入 Claude Code 写前提醒见 [宿主接入](references/claude-hook.md)；普通召回不需要读安装说明。
