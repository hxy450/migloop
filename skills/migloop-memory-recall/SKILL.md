# 按任务召回经验

输入是当前任务及经验包的 `index.md` 路径。先理解规格和源码，再用正常的文件读取能力查经验，不需要专用 MCP 或查询脚本。

本 skill 可单独发布；附带的旧库诊断脚本与 hook 安装脚本只依赖 Python，不需要其他 skill 或 inquiry 内核。正常召回只读指引和相关经验，不加载脚本源码或历史转录。

1. **看入口。** 打开根 `index.md`，根据一句话介绍选相关主题。每个目录索引只列下一层；可以同时读多个相关分支的索引。
2. **选经验。** 从经验预览的时机、情境和例外判断是否相关，再批量打开选中的经验文件。预览已能排除的条目就跳过。
3. **用于当前任务。** 对照适用条件采用相关做法，然后继续原任务。“可选检查”仅在条件不确定、与输入冲突或需要验证关键假设时按需执行，优先复用已有证据和正常测试；不因读到经验另起验证流程。项目原有必需测试照常执行。旧包标题为“检查”的条目也按此理解；不用遍历整棵树或列出所有无关条目的跳过理由。

文件名/API 已明确时可直接定位；不知道放在哪里时，可搜索索引，必要时搜索经验正文，按匹配结果选择文件。任务或输入明显变化后再补查，可复用同一版本下已读的经验。

经验是有条件的历史建议。当前材料与经验冲突时核实条件，再决定采用、调整或暂缓；历史样例的数值和局部修法不自动覆盖当前要求。简记采用的经验 ID/版本及对当前方案的影响即可。

只有需要复核才打开来源卡；核对结论时一起看其 `unknown`，区分已观察事实与新推断。来源不可访问或目录链接损坏时注明具体缺口。发布版本、来源复核及旧 store 入口见 [使用约定](references/usage.md)，遇到这些情况再读。维护者接入 Claude Code 写前提醒见 [宿主接入](references/claude-hook.md)；普通召回不需要读安装说明。
