# 同稿分叉复核：2026-09-14 预注册

目的：分离额外复核机会、构树写作负担和 inquiry 查询的作用。旧原始组与旧工具组产物不替换；不把本实验称为“只增加一个机械校验”的消融。本实验处理项是原始读取之外的 inquiry 核验能力及其通用使用说明。

## 固定对照

- 从 raw-high-i20-match-20260912 的同一条已完成原始调查线程分叉，A 普通复核、B 原始读取 + inquiry。保留其历史工具结果、推理上下文及最终稿；原线程不继续、不改写。
- 先跑 F10-06 / F10-09 两个已有开发样本，分别覆盖完整材料和材料本身存在缺口的场景。两臂均 Luna / high、相同 900 秒上限、无额外模型、同一材料池、同一复核 skill、相同交付要求。B 额外读取通用查询说明；新增说明的成本计入。
- 不提供预设缺陷、错误位置、金标或审查员意见。调查员自己选待核断言；不强制次数、路径、全树或新增输入表。
- 原稿不可变；只交“原主张 → 实际核据 → 保留/补充/降级/撤回”的变更记录及未决项。不重写全文，不因未提及而删除原结论。两臂都不得把复核过一条当成全稿已验证。
- 每个案例的两臂可同时运行，最多 2 个模型进程。失败留档、无自动重跑、无手工补答案。基础设施问题与模型失败分开报告。

## 评价和成本

主读物是原稿 + 复核变更及其实际附证，不是变更稿字数。按冻结的有限输入边界合同判断已证局部原因，不要求无限归到 skill。引用/工具自动绑定的原文只要直接支持已提出的窄结论，与正文引用等价；审阅者另找新材料才能补成的解释不算模型已完成。

逐案列出：纠正的实质错误、引入的新错误、正确结论的保留、补齐的相关输入边界、未决项、覆盖的原主张。除固定 28 个家族分数，还单列原有错误断言是否被修正；不得用机械通过率冒充归因正确率。两臂按同一标准，分歧引用必须人工核原文。

累计使用量包含原始调查；复核增量根据原生线程 usage 的继承/重置事实计算，缓存输入不重复相加。分列 token 总量、非缓存输入、输出、复核耗时、建索引耗时和端到端时间。fork 必须验证原线程未变、初始上下文保留以及两臂身份一致；验证失败不静默纳入有效对照。

## 进入下一轮的条件

两个开发案例不足以证明大幅领先。先确认交付和分叉有效；B 至少产生一项 A 未产生的有原文支持的实质纠正，且无新增实质错误，才将该方案固定后跑剩余 8 个既有文件。否则按实际轨迹定位障碍，另存下一版，不挑好结果覆盖本轮。

全 10 个文件的大幅提升暂定为有限输入边界已证家族数提高至少 6/28，且重大错误数不增加；同时报告逐案差异及不确定性。达不到就如实记录，不改金标来凑优势。构树保真、自动附证和加载能力随后独立测，不能用本轮散文复核冒充已交付可加载树。

## 2026-09-14 两例完成后的续批

两份非盲语义复核已落档：Guide 至少新增一条闭合归因（另有六组件引文/作者措辞瑕疵，保留记录）；Codex 两臂都修正证据边界，未发现工具独有收益或推翻核心的新错误。因此按原条件继续其余八个既有文件，两例不重跑、不替换，不向后续模型提供这些审阅结论。调查 skill、查询说明与产品代码保持试跑版；仅运行器支持显式选取已有案例，并适配原生 fork 的不可变父历史引用，防止把“不复制全文”误报为“没有继承历史”。

原 v1 严格复制检查告警保留；另存审计核实父 thread ID、结束 ordinal、字节界限、父文件哈希和 token 继承。后续冻结物也记录审计器与被复用运行器的哈希。审计可以查看旧轮次，但新执行必须匹配该轮冻结运行器，不能用后来实现静默重跑旧轮。

另做一次 Guide 构树收尾：只给模型自己的原稿、复核 delta 和产品技能，允许自由补查；无审阅者修正版或金标。单独计量节点原因保留、已证输入是否入树、真实传播边、加载状态及新增成本，不把它并入原始对照的复核得分。

## 封存续批之后的有界迭代

八例续批继续使用 `remaining-v1` 的封存实现与原说明，不吸收执行中发现的问题。Member 的工具复核新增了错误：由较早同形代码直接前移缺陷，未核后来才接入的真实数据；原结果保留。待模型并发空位释放，另存 `member-v2`，只跑一次 inquiry 复核，仍从同一个原始 raw 父线程开始，不继承失败稿、不提供评审结论。变更为通用的占位/真实数据、接线及启用条件核查规则和已提交的查询/构树修正。比较固定 raw 复核及原工具复核；不将定向开发重试当作新的独立配对优势，也不替换全十例成绩。

Guide 构树 v2 在 1200 秒内未完成，所有尝试保留。暴露的确定工具问题是显式 `cd` 与相对文件名分开时，原文确实存在但完整路径不能注册，尚未进入读写核验便被拒绝；另一项负担是边反复抄写同一节点长坐标。v3 从同一个成功的 inquiry 复核父线程重新开始，不输入 v2 失败稿。只修词法路径入口（不新增确定效应）、增加本稿节点序号边（仍调用同一校验）、更新通用说明，并把旧调查句柄追加到新导入账本。单次 1200 秒，记录结构/语义/原文送达及端到端耗时；仍不得把构树通过等同原因正确。
