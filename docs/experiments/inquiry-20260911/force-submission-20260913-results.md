## 落地范围

- 节点接受实际 agent key、完整转录名/唯一文件名或已有 scope；文件使用路径及时间。
- `edges:[{from,to}]` 自动核实两端范围内全部确定读写/派发，附上原始操作；不任意挑选一次，不认证内容传播。
- 首稿的 `force`/`review` 被拒绝；旧 `reviewed_edges` 不能绕过。先提交普通连接，反馈明确哪些缺口可复核。
- 下一稿 `revision_of` 引用服务器保存的报告。同一目标、相同两端及时间范围才可补 `force:true`；不同标签但相同原子不算改变身份。
- `claim/evidence/review:{at,quotes}` 必须可定位到所声明 agent 的原始工具调用或回执。引用与时间硬错误不能放行。补边固定为报告专属 `model_review/candidate`，不写入 effects。
- 已有反馈许可经过引用纠错仍保留；首次强制失败不产生许可。加载重核不会借后来的反馈让原本被拒绝的首稿变有效。
- 旧已保存卡片仍可重核加载；新提交走同一校验器。没有新 UI、图引擎或 MCP 工具。
- 修复结果节点正是声明的目标根，且有已核入边时，允许其原因引用后续 Read 观察，不再要求重复入边的写入引用；不放宽中间节点路径。
