2026-09-13。实现与实测已经完成；结论是**卡片可保存、载入、复查，成本下降，但本轮没有证明归因更准或上游机制调查更深**。不能将“能画树”当作“原因已认证”。

## 交付

- 技能：[migloop-investigate](../../skills/migloop-investigate/SKILL.md)，随附 [check_card.py](../../skills/migloop-investigate/scripts/check_card.py)。模型只接一句任务和本次范围配置，自由使用 MCP 或原始读取，然后提交、审核、补查。
- 继续复用 `inquiry/1`、file/agent + 时间、原有树页面及同一个加载器。卡片包含实际修改、节点理由/证据、未知、机制假设和优化建议；没有新增一套图引擎或卡片协议。
- 原页面“载入调查”的结论详情展开已有的建议/假设/未知。节点仍可手动展开，模型查询轨迹与历史关系分开；独立搜索不生成读边。
- 卡片原稿、引用、时间、节点、边和修改对账由脚本复核。输出 `ready_for_review / draft / invalid`；`semantic_verified` 始终 false。可送审不是可直接入可信知识库。
- 当前本机入口：<http://127.0.0.1:8878/>，按迁移进入页面，在左栏“模型归因”逐文件载入。页面读取独立索引副本，不改变调查员的原始记录。旧 F10 文件链接重定向到相应迁移及报告；旧 Guide 路径重定向到 0723 迁移入口。

技能部署时需提供 `investigation.json` 的 file/generation_end/observation_end/pool，以及审核用 runtime.python/index_path/code_root。当前短句为：

> 使用 $migloop-investigate，为 investigation.json 指定的被修文件制作并审核一张可载入的返修情景卡。

这不是一个独立证据 ZIP：短引用 YAML 仍依赖保留的索引和原始材料，不能只把一个 YAML 文件搬到空 server 后宣称证据完整。后续 server 接入需保留同一任务、索引、源文件及版本身份；本轮未实施登录看板的数据导入或自动发布知识库。

## 卡片自查实际改了什么

十份全部经历2～3次提交。首稿中把查询RESULT当原文引用、时间范围不覆盖引用、漏列待判断调用等问题，经工具反馈被模型修订；最终十份原稿的冻结机械检查均 valid，十份均真实浏览器载入通过。

- 可送审5张，草稿5张。会员/Splash的问题路径有未闭合；DiceIndex仍有128条相关调用未判定，不把它们自动视为128次写入。其它部分草稿保留未知效应。
- problem-path complete 标志为8/10，但其中4张没有声明问题节点，属于空集成立。真正有问题节点的6张中，4张路径闭合。不能把8/10宣传为八条完整因果链。
- Guide局部3/3，但本轮未发现已人工核实的三项深层事实：资源汇总丢4dp、safe-area交接缩成只处理顶部、实际检查PASS仍漏掉底部属性。独立深层复核为0/3，**不改变原28点分母**。
- 建树/查引用主要促成了坐标和修改清单纠错，尚未稳定促成错误因果主张的撤回。例：Splash仍把只改注释的Slice11 Edit当成删返回处理；Codex弹窗仍把修复者标红为进入点。

所以“制作情景卡促使核查”是可用机制，但不是自动正确性的保证。下一步应处理这些真实失败，而不是继续加一段“务必深入”的提示后宣称解决。

## 冻结跑完后修复，未回填分数

1. **补边身份矛盾**：真实引用不能把已索引的B写入绑定为A，也不能换成另一个文件。新校验在共用 `reviewed_edge` 中拒绝唯一调用锚点上的原生端点矛盾；真正不透明脚本仍可留候选。同记录多个调用不借相邻native块判定脚本，相关反例保留。
2. **旧缓存旁路**：手动neighbors仅重核本次相关的已存补边，不重建整份报告。旧版接受的错误补边不能从缓存重新出现；被拒绝项显式返回。
3. **没有生成过错也能展示树**：`repaired`节点进入展示路径，不进入问题路径计数，不自动染成生成过错。AppScope/签名两张原来只画根的卡，现在会显示其真实修复写者。没有新建虚构关系或修改节点理由。
4. 技能澄清：origin不是调查起点、诊断者或修复者；未知初次引入者可以诚实未知。此句修订未再调用模型，不宣称已提高准确率。
5. 修复suite监控把只允许新建的保存函数用于重复进度文件的问题；此次十个worker已正常完成，只有总监控退出1。原单例产物保留，汇总从它们重建，没有重跑调查员。

验证：**236项inquiry回归通过**；技能结构验证通过；原手动探索浏览器契约通过；十张同一原稿在更新后页面再次全部载入通过。一次浏览器启动遇到Windows `DevToolsActivePort`短暂锁定，修的是测试启动的限时重试，不是删失败模型或替换报告。
