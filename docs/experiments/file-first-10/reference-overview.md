## 为什么这些不是“我说对就是对”

每条可证判断都需要落到原始输入、源码/补丁、调用回执或测试返回；再主动找能推翻它的记录。例如“无 crash 报告”有更早真实 jscrash 回执反证，“没有回调接线”有父子源码反证，“生成忘改身份”有原始禁改指令反证。历史代理意见只算意见，不因重复出现而升级。

独立的 [audit_reference.py](audit_reference.py) 不导入 migloop，扫描三个原始池并核实原生调用身份、时间与成功回执。Codex code-host 的外层 call id 与内部 patch 事件 id 不同：保存内部事件自身的 changes/success，不按相邻行发明外层归属。此机检能证明修改资格，**不能证明上表语义归因全部正确**。

该扫描只自动登记 native Edit/Write 与 patch 事件。会员页、启动页的 Bash 脚本改动另有已审原文清单，不能把 native 数量当全部修改数。其余调用全部保留为效应复核分母，未穷尽的脚本和缺失子代理明确列为覆盖界限。
