## 哪些已证实是工具障碍

- 0723已知24个“目标文件×修改调用”中，首版changes只列20项；Member/Splash各自的mask与图像尺寸Bash修改未列入。原始索引仍有入口，但清单未给完整未分类余项数及逐项续读。
- 真实批量返回中，相关events整项因预算不足被deferred，delivery.records为空；不能说模型看到了这些原文，更不能把未交付理解为零命中。修正应交付可容纳前缀并给续读，而不是整项拒绝。
- 严格文稿格式通过仅9/20。未知键/重复coverage/漏reason等可使整张图为空，虽然正文有可审阅原因。格式不合规应继续报错，但展示可独立保留能绑定的节点；不修改原稿、不补造边。
- Codex代码宿主外层成功被误用作内层脚本操作执行证明。原生补丁与外层调用id不同，首版会同时列无作者的原生效应与归给主会话的解析操作。必须先撤回执行/作者升级，不能靠相邻时间强行配对。
- 未识别执行效应也可能使旧内容继续显示known；需要内容不确定性窗口与原始取证入口，不能把词法提及转成写者来修这个问题。

上述障碍解释了具体取证/展示失效，并没有证明它们解释全部分差。工具组仍有找到局部修法却漏生成输入、把未亲自验证扩大成历史无验证、在机制假设中夹入错误历史前提等模型推理问题。下一版同条件验证，不能预告一定获胜。
