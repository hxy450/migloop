## 安装器

- 默认首装仍拒绝同名覆盖。
- --update：完整暂存四包后，移动旧包至安装根旁的`.migloop-skill-backups/`，再发布新版。备份保留旧包内的自定义文件。
- --restore：恢复备份对应安装根的先前四包状态，包括先前不存在的包；恢复操作自身也可撤回。
- 普通失败回滚；回滚失败保留备份、暂存和manifest。安装锁阻止并发安装，链接/junction目标拒绝替换。
- 更新期间应停止使用四包。强杀/断电恢复仍需要核对manifest，四目录替换不声称全局原子。

README与VALIDATION已统一：0.2.0的旧包备份是当时开发者手工操作；0.3.0才具有自动备份/更新功能。
