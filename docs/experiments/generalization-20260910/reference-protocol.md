## 调查问题与证据范围

问题只给目标文件和生成/观察时刻：查清生成截止后实际发生了哪些修改、为什么修改、为何生成截止时未做成；允许答案为后置新增要求、返修引入、未确认效应或更深原因未知。不预置缺陷名、数量、作者或检索词，也不要求原因必然落在 skill。

取证以冻结原始池为准，工具只是可选导航。不得执行历史脚本或构建命令。参考必须检查完整观察窗口内的原生写入，以及命令、脚本、输出中目标相关的候选效应；不得只看 Edit 列表。两个时间锚点间的间隔也在调查范围内。未知时间附件可以解释文字来源，但不能借文件时间、工作流摘要或文件名推成已送达的生成输入。

## 先建修改对账，再归并核心

每个文件保留独立的 reference artifact，至少包含：

- 每个已确认修改的原生 use/result、时间、路径、内容/片段以及前后状态；同时列未决候选、失败、部分成功、不透明命令和连续性缺口。
- 按目的归并的修改族及其原始成员。一个原因可以解释多次修改，一次修改也可以涉及多个原因；不要把每次工具调用当作一个缺陷。
- 对每个修改族说明已证局部原因、已知生成输入、输入是否确实送达、输入与输出的关系、后续要求来源；无法建立者明确未知。
- 对最有可能的相反解释记录核过什么及原文反证。不把 agent 自述当作独立事实，也不从未检索到推为全池不存在。
- 测试/构建证据分别陈述静态、编译、安装、行为层级，不用构建成功证明行为正确，也不因为没有行为复测就说没有构建。
- 修改对账：每个确认修改归属哪个修改族；哪些只证明过程/格式调整；哪些仍不能归因。未知项不能静默从分母消失，也不能强迫模型捏造确定原因。

core artifact 使用 `migloop-causal-core-contract/1` 的 `units` 映射，键为 `TASK-ID/稳定修改族名`。每条只写不可缺少的局部修改/因果/责任边界，不把全部辅助细节塞成满分必需条件；语义等价和不同分组均接受。参考更深的机制假说不自动成为必答核心。

没有可确认局部原因时，核心允许有界未知：要求正确识别已确认修改及不能进一步归责的具体证据边界，不能把一句通用“不确定”记为正确。若原始资料不足以解释一个文件，保留该文件及资料不足标记，不换成容易的文件。所有入选文件必须有修改对账和明确的可评范围。

## 独立复核与冻结

每个 reference/core 由一个建立者取证，另一审阅者回看原文，重点审最早引入/继承、已读与只提到、后置要求与生成违规、失败命令和生成截止间隔。审阅不是盲目多数投票；分歧必须列出原始定位和裁定依据。记录审阅者、原文范围、未决分歧。AI 审阅不称人工双盲。

必须在任何新调查模型运行前完成 reference/core 的独立复核并冻结 SHA。正式 private 合同含每队列完整 task_ids、boundary_gap_reviewed 及 reference/core artifacts，绑定 source/candidate，时间晚于 candidate freeze。执行器只读私有字节哈希，不解析或交付答案。建立参考后不得调整该候选的工具、GUIDE、问题或预算来迎合答案。

## 原始组与工具组同一语义尺

核心仅取 correct/partial/missing/wrong：correct 要解释核心局部原因且责任边界没有被自己推翻；partial 不是完全错误，但不计入 correct 分子。缺少非核心辅助细节不清零。报告所有实质因果主张另去重为 supported/contradicted/unsupported_asserted_as_fact/explicitly_hypothetical，保存精确报告引文和原始依据。无事实断言时 precision 为 null，不是 100%。

major 必须是实际错误主张改变了核心修改、原因、责任阶段/作者或行为验证结论；仅遗漏、合理未知、YAML/引用错误不是 major。普通“没有看到历史构建”若实际有构建，记矛盾；如果报告进一步以此作为“整个生成无验证所以生成错”的因果前提，则是 major。不能以工具组有更多可机检字段为由只罚工具组，也不能为 raw 缺结构化格式扣归因分。

主要数字：每队列文件等权 correct coverage、correct/全部核心、支持/事实主张、完整文件通过（核心全部 correct 且无 major）、major 数。不得把 26 跑或跨队列所有修改族当成 26/若干独立业务样本。还需单列完整无事实矛盾/无无依据断言的报告数，不能把“核心通过”说成全文完全正确。

审计另报实际访问/正文交付/引用定位/节点身份/历史关系/未知关系/结构化载入；这些不是归因加分。成本累计 input+output，缓存输入单列不重加；调查耗时、含验证的端到端耗时、并发队列耗时分开。未跑和缺记录不记零成本；终止且没有最终答案按未完成交付处理，不能删除失败。

真实额外发现不是错误。若新证据推翻参考，新增修订日志与参考版本，对两组对称重评并保留原始分数；不能静默移动答案来保证某组获胜。首次解盲后再调优的样本转为开发曝光，下次不能继续称留出。
