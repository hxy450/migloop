## 任务

文件 `{file}` 在修复轮被修改过。请查清:修复改了什么、凭什么改、被它改掉的代码原来是谁在什么依据下写的、
生成时为什么没做好(问题出在生成链路的哪一环)、这次修改是否必要。一直往上游追,直到能说清。

## 要求

- 每个断言指回工具坐标(path@v / agent vK / #n),不引用不算证据;说不清的如实写「无法确认」。

- 工具调用尽量控制在 25 次以内。

最后**只**输出下面这一段,不要别的前言:
