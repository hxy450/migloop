# V8：可调用坐标、证据边界与两层图

在V8调查产物出现之前记录。V7四跑保留；原始题目/池不变，reference-v1不改，新五题oracle不参与调优。

## 这次改变什么

- action可直接接完整ref，按转录标识/行/块唯一定位，并交叉核原始source指针；序号漂移明确提示。原id+seq兼容，唯一旧别名显式说明解析，错误owner不再按全局seq落到另一代理。ref与id/seq互斥，分页/原文范围不变。
- 文件/候选中的人类代理标签附实际id，不让模型从转录后缀猜agentID。HTTP和MCP的已验证别名使用同一个canonical target，避免HTTP先认可、后渲染找不到。
- 红节点basis.actual_evidence增加有界机械诊断：不确定/不同版本读、严格后置的引用、同代理窗口外/尾后事件。警告不判语义、不改原角色；不扫描散文、普通evidence或expected_evidence，无警告不代表主张正确。确定的同path同版读不被另一条不确定读否定。
- UI分开“文件关联未绑定”和“文档/引用身份未绑定”，前者不再禁用后者的真实原文入口，不以root补repair。
- 图同时可投影真实导航转移和已认证文稿显式选择的真实读写关系。模型选边须重核方向、版本、原始动作；额外端点灰色未查询，query_steps可空，不新增访问。搜索、路径提及、implicit相邻、派发和未确认的模型关系不变成读写线。所有来源分别留存，图不是全账本/全根因证明。

这是组合版本，不把整体结果归给某一项。暂不改变两原子定义、agent默认历史范围、v1 YAML schema或coverage逐项契约；三者的替代设计另列提案，不混入本轮。

## 实验固定项

- GPT-5.5 medium/native，工具组reference最终交付，单跑1800秒，不暗中续跑或修复重试。
- 七文件/十题，每文件两次工具调查；初始队列顺序Member、C4、Dice、Splash、C1、C2、C3，再同序rep2。开始后源码/runner冻结；严重实现故障需另版本，不把不同候选拼成一套分数。
- 原始组为相同题目/池/模型的V6B Member+C4各两跑，以及正在补齐的V7其余五文件各两跑。原始组不承担当次工具UI/YAML义务，额外审计成本属于工具产品成本，不伪称纯检索器消融。
- 合计最多两次模型调查并发。所有失败/超时与成本保留。

## 验收

主成本input_total+output；另列uncached+output、cache、端到端时间及真实用量增量轮数，不能将MCP调用数当模型轮数。目标完整集合总量节省20–30%，同时列等权任务降幅与重复差异，不挑较便宜样本。

逐题按旧protocol核心/完整说明分别裁决；原facts细项可标supported/partial/omitted/contradicted，但其比例不冒充总体准确率。要求有证据的归因、重要反证和时间/作者正确；少写或全未知不算提高。工具组如果仍错归责，即使token达标也不通过联合验收。

最终YAML/哈希/引用/图和原始调用可回查；真实页面验新增灰端点/显式边来源及原因原文，不仅靠字符串测试。旧报告可用新查看器另审，但注明两个版本且不改旧产物。
