## 两道独立验收

1. 归因：修复事实正确；当时适用要求/实际输入/后续变化分开；近因有证据，反证被处理；未知没有冒充结论。重要事实错误、时序越界或无依据归罪单独列失败，不用总分冲掉。
2. 审计：节点与版本真实；成功/失败/截断范围可回查；真实关系、候选关系、调查跳转、模型主张彼此分开；搜索发现未被历史 agent 读取的 spec 不制造读边；UI 与 MCP 共享事实/置信标签，折叠只改变展示量。

引用有效只认证位置；覆盖对账只认证有限清单有交代；测试通过不认证模型解释为真。设备截图在记录中被提及或保存，不能自动当成本次调查实际看到的图像。
