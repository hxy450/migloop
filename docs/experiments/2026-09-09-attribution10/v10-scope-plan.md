# V10 固定观察范围：先解决身份切换，不放宽证据校验

V8 C3 rep2 已实际发生：模型将 SID 从修复根换到生成根，服务分别构建2-root和1-root账本，最终身份保护拒绝提交。模型虽被提示始终使用当前根，工具仍需让这种范围变更显式化。

## 契约

- 仅在显式实验模式启用 `MIGLOOP_FROZEN_POOL`＋`MIGLOOP_FROZEN_ANCHOR`＋`MIGLOOP_FROZEN_ROOTS`。最后一项为调用者选择的顶层 root 路径 JSON 清单，必须包含 anchor。
- 同一清单内的 SID 都是该观察范围的入口别名。所有账本、阶段、MCP、HTTP与查看器用同一 anchor 和同一根集合；查询过去用版本／时间参数，不通过切 SID 隐式换账本。
- 清单边界、格式、路径、时刻和别名必须验证；池外、未声明根及 anchor 后的新根不接受。配置缺项明确拒绝。
- **不能按 cwd 相同推断工程范围**：真实 C3 生成根 cwd 为 `/Users/ventiu/Desktop/HUAWEI`，修复根为其 `AIPPT_830_test` 子目录。按 exact cwd 过滤会丢失真实生成证据。显式纳入一个根仅代表调查者选择了范围，不证明两个根语义上属于同项目。
- 未开启 anchor 模式时保持旧行为；低层读取仍按实际根，不把历史原文重写成 anchor。
- 账本身份保护不变；已混合范围的旧运行仍判无效。旧源、旧运行、V9候选与 holdout 均不改。

## 配套与验证

Harness 在 MCP 配置、子进程环境和运行元数据同时记录 anchor/roots，后置审核恢复同样范围并恢复环境。审计脚本按运行实际记录的配置重放，不继承查看器环境。CLI `--serve` 直接交服务定位，避免先全局发现到同 SID 的 live 副本。

验收包含同一池跨 SID 保持 ledger identity、真实父/子 cwd 两根都保留、未声明根拒绝、缓存与阶段一致、MCP/HTTP一致、旧模式兼容，以及伪造或真正混合身份仍然拒绝。该改动解决范围歧义，不被计为已经提高语义准确率或节省 token；付费复测应另用冻结 V10 源和新运行目录。

## 同版的保守呈现优化

`agent(summary_chars=96)` 默认只缩短动作摘要，`200/600` 可展开账本已有摘要，完整原文仍用 action。每条动作、版本、时刻、读写集合与引用不因这个参数删除；未解析命令也保留索引和不确定标记。不将新默认变成只显示最后一个窗口，不按模型关注点裁掉早期输入。

离线相同 C2 `agent(__main__:01a021e5,v=218,reads=False,seen=True)`：328,419 → 292,990 字符，减少10.79%；2,120条动作、155条读、280条收件及 ledger identity不变。**仅是单次返回的字符差，不是整场 token 或时间收益。** [诊断脚本](inspect_agent_budget.py) 可重跑。

候选冻结后计划重跑原开发集七文件各两次 GPT-5.5 / medium / native，使用同一原始组14次基线，计入全部运行，顺序 C3、C2、Member、Dice、Splash、C1、C4，先rep1后rep2。观察范围、摘要预算改变是本轮处理；共同任务、数据池、既有语义 rubric 不变。与V9及raw分别对照。已用过的holdout不重新冒称盲评；本版不用于替换预先选定的V9盲评候选。
