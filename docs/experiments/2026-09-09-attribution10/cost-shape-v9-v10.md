## 已核到的损耗与边界

1. **不是笼统的“重复 search”。** V9 108 次、V10 107 次 search；按除 q 外参数完全相同分组，分别有 20/19 个多次查询组，覆盖 101/98 次调用；其余词可能是后来读材料才提出，不能据此承诺一次合并所有调用。V9 C1 #10–14 在同一 agent/截止范围分查 return、empty、no-op、lint、static，共返回 106,143 字；V10 C1 改用较小版本窗，全部 search 返回由 135,401 降至 22,590 字。相反 V10 Member 全池 `renewRuleDialog` 一查就返回 35,959 字，仍明确省略 11 个文件、39 个 agent（L201→212），不是全量正文。

2. **via 摩擦确实阻断窗口，但不等于从未取得任何依据。** V10 Dice 对 fix-errobserver@v3 的 #10/13/14/18/19/20 全被拒绝，其中 #18/#19 完全同参；L116→121 与 L127→130 把人类标签 `agent:主会话·2f01bcdc@v5` 当机器地址，返回“via 解析不了或不在账本”。#20 改写成函数式地址仍被拒（L136→139）。不过之后 #24/#25/#26 已用 action 取得该代理的原始输出，不能把 agent 未打开扩大成“没有读过该代理证据”。

3. **请求不同文件片段，实际反复拿到同一份未知内容索引。** V10 Member #11（start=190,n=60，L61→70）、#16（同正文窗口、换 via，L84→93）、#17（start=700,n=55，L85→95）均返回 18,202 字，正文 SHA256 完全相同：`b73c6a4c1fee3c9bcba4cf74ea6fbf4fd6d6a43062fd7a52ded00db47ad7f606`。尾部都是 `## 内容: 无法复原`；首次之后重复交付 36,404 字，不能按请求参数声称看过相应行段。

4. **长前缀与截断不能证明完整输入。** 成功的“since 未给/为0、until 未给”累计前缀 agent 查询，V9 为 9 次/131,288 字，V10 为 6 次/106,800 字；它们仍受 v 约束，不能全部叫完整生命周期。Splash 各有两次真实运输截断：V9 #3/#14 中间共未交付 39,748 字；V10 #33/#43 共未交付 28,918 字。V10 #33（fixer@v40, reads=true,seen=true；L153→162）原生返回 70,093 字，实际交付 41,300 字（含省略标记），其中 28,816 字未交付。统计保留交付体，不拿原生完整体补成模型已读。

5. **find 未命中自动给长开头，会重复付出窗口成本。** V10 Dice #24（L154→163）找 `interface ErrorObserver`，#26（L168→171）找 `onUnhandledException`，均指同一动作 #4500 的 output，均明确“未命中”；仍分别返回该字段第 1–7000/1–5000 字，工具总返回 13,407 字，共同前 5,000 原文字符重复。不能把这些前缀当成完整 SDK/另一个 ErrorObserver 文件的不存在证明。

反方校验：并非每个错误都能推给截断。V9/V10 Member 的脚本 action 都完整交付了 `if builder=='AppLoadDialog'`→`Color.Transparent` 分支（V10 #3，L35→44，5,046 字），两轮最终稿也都正确区分三站点取值。本次不沿用更早轮次“3 sites 被概括成 3 处深色”的错误标签。只从调用记录不能证明模型内部为何作某个归因；机检通过、打开节点和收到片段均不是语义正确证明。

## 仅两个非案例硬编码候选

- **同范围受控字面量 OR + 全局预算。** 多词一次扫描、逐词/来源公平示例，保留未知、未展示计数、原始定位与精确 receipt；不把搜索变读写边。优先降低宽范围多词单查的重复上下文，不强迫合并依赖前一步才产生的问题。q_any 已是下一源码候选，但不属于这两轮冻结源，尚无本报告中的实际节省证据。
- **不可满足的展示请求先短回执，再显式展开。** 对 file 正文不可复原、action(find) 未命中，先给实际能力/匹配状态、请求与交付范围、稳定原文定位和可复制的已打开 via；正文/完整索引仍可按需展开。不要默默返回长索引/长开头，让新窗口像新证据；同一原文哈希可提示重复范围，但不得自动删掉用户要看的原文。该方向同时减少 Member 的重复索引、Dice 的重复前缀和地址拼装重试，不降低身份/来源门槛。
