传递(照上游做的)/ 错(有好的输入没用或用错)/ 缺(输入里本来就没有)。一直追到池外输入(安卓源码、真实后端响应、模板)、

以及修复侧比生成侧多看到了什么(运行期观测 / 截图 / 编译输出 / 接口探测 / 授权口径 / 晚出生的现成件 …)。
