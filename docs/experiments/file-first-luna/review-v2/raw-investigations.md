## 7. 新发现的实验混杂与可以得出的结论

所有12次调查的原生转录L3都有相同宿主skill目录/指令，两个raw首跑实际读取池外skill。未发现因此读取了评审答案；但“忽略用户配置/规则”不等于宿主developer内容已经隔离，不能继续称纯冻结池对照。两组都有指令注入、执行能力却不同，影响方向和幅度未知。

本轮旧成本/报告仍是历史事实，可继续用于诊断，不丢弃不利结果，也不马上重跑。未来若修复隔离条件，应登记新的实验条件再做最终公平验收；本次不改全局配置。

当前证据支持的改进次序：稳定读取/目录/编码→有边界的修改清单→从写入找实际前置输入→帮助核对已见事件与最终解释→保持精确引用和树上展开。不是再加一段“模型必须深入”的提示，也不是证明更换成skill形态就会自动变准。

## 8. 仍需验证的假设

这些观察说明了失误发生的位置，尚未通过新实验量出每种工具改动的增益。尤其“证据交付后仍漏总结”不能仅靠索引解决；需在不灌入参考答案的前提下比较修改清单提醒、相关输入展开等通用能力。模型注意/理解和唯一认知原因不可由日志证明。
