# 单一时间证据树

2026-09-12，用户确认实施。主目标是从被修文件逐层向上展开的可复查树，不是把查询顺序画成因果关系。本轮不重跑原始评测或真实迁移。

## 边界

- 唯一活动树位于 `inquiry/page.html`；删除被替换的三份旧树模板。普通报告仍链接原来的 fixchain URL，挂载与独立 inquiry 服务使用同一个页面、HTTP应用和查询内核。
- 不复制旧版本状态机。file/agent 是历史时间范围；边带实际操作时刻和原始事件身份。同秒不合并操作，不把时间当事件ID。
- 保留普通报告仍依赖的旧账本与旧API，明确它们没有整体退役。不删除历史原始数据、冻结实验、用户未提交改动。
- 旧 `?probe=目录` 不猜成新 `report_id`；明确提示旧格式未载入。现有 inquiry/1 原稿保留，新增可选关系复核字段，不改原始事实。

## 同一个展开契约

`file/agent(view=neighbors)` 是同一 Engine.query 的投影，MCP、CLI和UI均可调用。默认向上游：文件找写者；agent找已返回的读输入及显式派发父节点。也支持下游；分页、范围、未知时间和候选强度保持可见。

每行返回稳定边ID、读/写/派发类型、实际时刻、依据、来源/强度及另一端的时间坐标。报告自动展开与手动展开复用同一行构造器及前端插入逻辑。不需要调查员维护via。

同步派发的发生与确认分开：request 时刻是派发发生，result 时刻才确认原生父子身份。查看子代理执行时、父调用尚未返回的窗口，关系标候选及“身份来自稍后回执”，不提前展示未来回执正文。手动查询、报告核边与树回溯共用时态投影，不用前端特例提前画实线。

报告树根是目标文件截至观察结束的完整历史入口；原目标修复区间另行保留，不能因查看更早历史修改原任务窗口。文件历史范围不是最新完整内容。模型对特定历史操作的判断，保留原稿坐标/原因，不能把整个文件生命周期一并认证为坏。

## 补充虚线

原生可核关系保持实线；索引候选仍虚线。未被解析器识别的读写可由同一调查员复核后提供 `edge.review = {at, quotes:[{ref,text}]}`，沿用 edge 的 from/to/relation/evidence/claim。

优先放在 finding 的可选 `reviewed_edges` 中，与自动生成的原生边叠加；不必为一条补边手写其余所有连接。MCP submit 单独返回 `path_status` 和逐问题节点的状态，不把坐标核验 `mechanical_status` 混作路径闭合。

复核边要求合法两端、方向、时刻与可定位的原文摘录；摘录必须逐字存在于其引用的原始记录内容中。至少一份依据发生在所声明操作时刻。它仅认证引用/时间/摘录存在，**不认证这句话在语义上证明读写**；来源始终标 `model_review`，强度candidate，存在于报告层，不插入effects表。无依据的猜测或独立搜索不创建读写边。

## 从问题到目标

在报告已引用并核回的关系中寻找时间不倒序的路径，显示从根向上游的展开步骤。所有模型声明的 origin/propagated 都有 native/candidate/model_review/unclosed 路径状态。没有原文可接的节点列入断点，不摆成假连通树。

路径只说明历史读写/派发可接，不认证错误内容连续传播或唯一根因。派发不自动证明输入内容传递。不同历史范围通过真实操作展开，不凭同文件名添加“版本连续”边。与节点对应的操作需要该节点所引证据支持，不能借一条无关写操作完成它的路径。

目标修改锚必须由 changes 引用命中的目标写操作、或该问题的已核模型复核目标写支撑。只有 Read/grep 命中文件名不算修复锚。候选修改锚不会使路径被标成全原生确认。

首屏只展开报告的证据路径；其它邻居懒展开。同一祖先范围再次出现时停止递归并保留引用标记。用户新展开的内容不加入模型调用轨迹，不改模型原稿。

跨原子展开会明确打开“另一个实体截至该操作时刻的完整历史”（新的 since 为空），以便看到当前窗口之前的输入作者。这不是扩大原稿主张的范围；同原子原文续读和原稿引用仍守住原来的 since/at。

## 服务与索引

旧 `/api/insight1/fixchain/<sid>` 和独立 inquiry 服务共同挂载 `inquiry/web.py`。旧入口按已选择的会话根、明确子代理元数据与源文件统计生成可复用 SQLite 快照；热查询不重建账本、不重读全部转录。源集变化产生新索引，旧报告留在原索引，不自动移植。冻结 anchor 严守配置范围。

这不是删除全部旧后端：普通迁移报告与旧 MCP/API 仍依赖的账本保留；本轮消除的是重复活动树和重复 UI 查询语义。

## 验收

1. 手动与自动沿同一事件得到同一两端与依据；多个问题共享前缀、未闭合条目、同秒事件、循环均可正确展示。
2. 更早节点看不到更晚返回；节点、缓存和分页不丢since；原文/补丁保持可展开。
3. 有原文摘录的模型复核边画虚线；伪造摘录、倒序时间、错误方向、无依据边不能画；不会改变effects/原调查。
4. 普通报告链接和独立服务进入同一树；旧模板退出打包；无旧版本查询假适配。
5. 固定真实报告只读载入验证，保留断点；不改报告追求漂亮连通。用一份真实报告演示展开、节点原因、原文及切换问题。
