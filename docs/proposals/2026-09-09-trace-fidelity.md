# 2026-09-09：忠实路线与可核主张

本轮接续 `7a03465`，服务于两个验收目标：页面忠实呈现模型的实际调查；在事实质量不退步时降低成本，或证明重要遗漏/错误归因减少。

## 保留两原子，但不混淆四层

- 实体：`file@版本`、`agent@版本`。不为搜索、思考、报告再造第三种原子。
- 访问：带原始调用身份、请求参数、调用/返回位置及状态的一次事件。同一实体可回访，重复/自环/多来处都保留。
- 关系：`via` 是模型声明的导航来源；读/写/派发是账本另行核对的关系。探索跳转不是因果证明。
- 主张：每条缺陷在精确节点上的 role/reason/evidence。模型主张、引用可定位、断言真伪分别处理；历史账本身份不符，不把同号版本硬绑到当前树。

这是一份可审计调查记录，不是模型全部私有思路的记录，也不因为可视化了就证明归因正确。

## 已实现的主要约束

file/agent 先验证目标版本，实际返回坐标匹配后才登记打开；状态限于服务器实例且按账本身份归并会话别名。区间 diff 不再偷偷切换请求锚点。

probe 以调用与返回配对，保留失败和未完成。实体合并不删除访问；布局树不能替代完整转移集合。结论独有节点不标成查过，A/B 缺陷切换同步原因面板。浏览器测试覆盖真实点击、回访、自环、多来处、错误版本与无有效根。

账本身份在建账完成时冻结，以源内容及实际建账产物签名；不随原文件后续修改改变既有内存账本的身份。模型、harness、当前账本身份独立核验。YAML 重复键、别名、非字符串键和过深输入拒绝，不能让模型自报检查变成机检。

默认文件查询只展示提及候选计数，显式分页可恢复。不能从节省字符推出节省 LLM token，更不能推出质量不变。正式输出直接是结构化结论，避免另写同义长报告。

## 停下与归因

不写死“零命中就缺、有命中就不准停”。要求在当时适用、生成方确实获得相关输入、实现与要求的具体落差，才支持该节点“进入·错”。无关搜索命中无需无限追溯；未检索到只支持有范围的未知；后期新增要求/插桩不自动构成初始生成缺陷。

## 实验边界

正式调查员采用用户指定的 `gpt-5.6-sol / medium`，raw/tools 共用冻结池、共同任务和隔离设置。评审原始证据包不送给调查员。源码/池/提示/原生事件/失败均归档。`MIGLOOP_FROZEN_POOL` 模式阻止工具回到真实工程、用户会话目录和实时源码补全；正常用户模式不变。

协议与成本测量在 `docs/experiments/2026-09-09-fidelity-cost/`。最终是否提效由成对运行和独立原文核验决定，而不是测试数或引用数。
